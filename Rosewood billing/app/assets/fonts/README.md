# Document fonts

Noto Sans Regular and Bold are distributed unmodified under the SIL Open Font License 1.1. The accompanying LICENSE file is mandatory.

Source: [notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/tree/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf/NotoSans), pinned at `ffebf8c1ee449e544955a7e813c54f9b73848eac`, retrieved 12 September 2026. These fonts provide embedded Latin, Greek and Cyrillic glyphs for reproducible PDFs. The renderer refuses unsupported glyphs with an actionable error instead of silently dropping student/payer characters; a wider approved font can be configured with `BILLING_FONT_REGULAR` / `BILLING_FONT_BOLD` when needed.

These fonts are the only upstream visual assets included in the billing app. School/product source code or templates from the research corpus are not included.
