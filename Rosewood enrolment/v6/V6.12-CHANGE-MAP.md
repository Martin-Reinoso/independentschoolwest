# V6.12 Immunisation Guidance Change Map

## Scope

V6.12 is an immutable presentation-only EOI and Application release. It preserves the
V6.11 data contracts, answer keys, validation and backend behaviour while repinning the
shared family interface assets.

Current contracts:

```text
EOI:         rosewood-eoi-2026.12
Application: rosewood-application-2026.12
```

V6.11 and every earlier definition remain addressable. Submitted records, saved
answers and signed evidence are not rewritten.

## Family Interface

- The Medical Details guidance now states that Victorian primary-school enrolment
  requires an Immunisation History Statement regardless of the child's vaccination
  status.
- The guidance now says families can obtain "the statement" through myGov.
- "Victorian law" remains linked to the official Health Victoria primary-school
  immunisation requirements page and is now visibly underlined, uses the Rosewood
  terracotta accent and includes an external-link marker.
- The existing screen-reader-only "opens in a new tab" label and keyboard focus ring
  are preserved.

## Data And Workflow

- No question, answer key, required field or conditional rule changes.
- No new acknowledgement or inferred consent is introduced.
- No schema, DynamoDB, Google Sheets, Google Drive or signature change is introduced.
- EOI advances to V6.12 only because the family HTML, JavaScript and CSS are shared and
  repinned together.
