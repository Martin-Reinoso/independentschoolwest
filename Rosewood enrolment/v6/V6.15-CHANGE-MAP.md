# V6.15 Family Question Clarity Change Map

## Scope

V6.15 is an immutable shared-interface release.

```text
EOI:         rosewood-eoi-2026.15
Application: rosewood-application-2026.15
```

V6.14 and every earlier definition remain addressable. Submitted applications,
submitted answer snapshots, documents and signature evidence never upgrade.

## Family Wording

The Application Student page now asks:

> Do you have any other children, apart from this child, who may apply to Rosewood
> College in the future?

It adds the note **Do not include the child named in this application.** When the family
answers Yes, the revealed required field is **How many other children may apply?**

The existing stored keys remain `future_siblings` and `future_sibling_count`. The count
remains a whole number from 1 to 99. No answer meaning, required rule, projection,
decision rule or retention behaviour changes.

## Validation Navigation

- An unanswered Yes/No question reports: **Please select Yes or No for “Do you have
  any other children who may apply?”**
- A missing count reports: **Please enter how many other children may apply.**
- An invalid count explains the 1-to-99 whole-number range.
- The validation action carries the exact field identifier. It opens the Student page,
  updates conditional visibility, scrolls to the affected question, highlights it and
  moves keyboard focus to its control.
- Internal names such as “future siblings” are not shown to families.

## Compatibility

Opening an editable older application upgrades it once through the existing conditional
definition transaction. Every saved answer is preserved and V6.15 performs no value
normalisation. An already-open V6.14 application session remains valid and its existing
draft contract remains accepted; the clearer interface is loaded after a normal page
refresh or later sign-in. Submitted applications and signing reviews remain pinned to
their original wording. New V6.15 guardian reviews use the clearer labels.

EOI advances only because EOI and Application share the versioned family HTML and
JavaScript assets. EOI questions and storage are unchanged.
