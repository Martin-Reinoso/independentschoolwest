# V6.16 Melbourne Signing Date Change Map

## Scope

V6.16 is an Application presentation-only release.

```text
EOI:         rosewood-eoi-2026.15
Application: rosewood-application-2026.16
```

V6.15 and every earlier Application definition remain addressable. Submitted
applications, frozen reviews, documents, primary signatures and guardian signature
evidence never upgrade or change.

## Guardian Signing Date

The read-only Date field on the additional parent or guardian signing page now uses
the calendar day in `Australia/Melbourne`. The earlier browser expression converted
the current instant to UTC before extracting its date, which could show the previous
day during Melbourne mornings.

The backend continues to record the authoritative signed timestamp in UTC. This
release does not change that timestamp, signature evidence, OTP verification, review
acknowledgement, declarations or submission behaviour.

## Compatibility

- The corrected signing script has a new cache version so an invited guardian does
  not receive the earlier UTC implementation from browser cache.
- The family Application entry script recognises `rosewood-application-2026.16` and
  retains support for V6.15 and every earlier addressable version.
- Existing open V6.15 sessions and drafts remain valid. A refreshed editable draft can
  upgrade through the existing conditional transaction with every answer preserved.
- EOI remains `rosewood-eoi-2026.15` because no EOI interface, question or behaviour
  changes.

## Verification

The automated signing regression requires the Melbourne time zone, the versioned
signing asset and removal of the UTC date-slicing expression. A boundary check confirms
that `2026-08-22T16:45:05.546Z` displays as `2026-08-23` in Melbourne.
