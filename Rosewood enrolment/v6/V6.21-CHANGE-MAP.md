# Rosewood V6.21 Change Map

## Scope

V6.21 makes the authenticated **Enrolment planning** list identifiable before a family
has entered child details. It does not change a family question, answer, requirement,
upload, signature, invitation, submission or acceptance workflow.

## Planning Identity

Each authorised application row now includes a response-only `parentGuardianName`
derived in this order:

1. primary parent/guardian answers already saved on the application
2. the parent/guardian name on the invitation
3. the name on the originating public Application-link request

The row also reuses the existing `recipientEmail` already available in the staff
Applications workspace. When the child name exists, it remains the title and the
parent/guardian appears beneath it. Before child details exist, the parent/guardian is
the title and the interface displays **Parent/guardian · child details not started**.

Search includes student, parent/guardian, invitation email and application reference.

## Privacy Boundary

The parent/guardian name and email are available only inside the authenticated staff
dashboard response. They are not added to the aggregate `planningSummary`, Admissions
overview, attention items, Google Sheets or another stored record. Health, document,
network, signature-image and detailed answer data remain excluded from planning.

## Layout

The desktop dashboard supports a wider maximum canvas. The planning panel uses less
side padding and denser cards while retaining readable line wrapping. Mobile keeps the
identity block full-width and does not introduce horizontal scrolling.

## Compatibility

EOI `rosewood-eoi-2026.20` and Application `rosewood-application-2026.21` preserve the
V6.20 family contracts. Editable older drafts use the existing conditional upgrade
without answer transformation. Submitted applications and signature evidence remain
pinned to their original definitions.

## Verification

Release verification covers parent/guardian derivation, invitation/request fallback,
contact-aware search, aggregate privacy exclusions, immutable asset hashes, desktop and
mobile layout, keyboard behavior and the complete backend regression suite.
