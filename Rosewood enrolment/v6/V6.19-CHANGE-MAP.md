# Rosewood V6.19 Change Map

## Scope

This release adds a read-only **Enrolment planning** section to the authenticated staff
portal. It does not change the family application questions, required answers,
submission logic, signatures, invitations or stored application data.

## Planning Projection

The staff dashboard summary now returns the existing per-child `entry_year` and
`entry_level` values as `entryYear` and `entryLevel`. The planning screen combines them
with the already approved operational summary fields:

- student name
- application status
- completed and required signature counts
- last activity
- staff-review flag
- application reference

The planning renderer does not use recipient email, health information, documents or
detailed application answers. Staff can search by student or reference and filter by
entry year, entry level and application status. Missing values are labelled **Not
provided yet** and can be filtered explicitly; no value is inferred from another
record or timestamp.

## Compatibility

EOI `rosewood-eoi-2026.18` and Application
`rosewood-application-2026.19` preserve the preceding contracts and repin only the
updated staff assets. Existing drafts, submitted applications, signatures, invitations
and revisions remain unchanged and addressable under their original versions.

## Verification

- backend summary tests cover entry year and entry level while retaining sensitive-field
  exclusions
- static interface tests cover the planning section, filters, operational fields and
  exclusion of recipient email from the planning renderer
- desktop and mobile layouts keep year and level visible
- the complete backend suite, deployment build, static-site gate and public-data gate
  must pass before release
