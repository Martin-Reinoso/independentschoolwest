# V6.14 Family Feedback Change Map

## Scope

V6.14 is an immutable EOI/Application interface and validation release.

```text
EOI:         rosewood-eoi-2026.14
Application: rosewood-application-2026.14
```

V6.13 and every earlier definition remain addressable. Submitted applications,
submitted answer snapshots, documents and signature evidence are never upgraded.

## Family Communication And Verification

- Direct invitation email keeps only: “Thank you for considering Rosewood College for
  your child’s education.” The linked-EOI invitation is unchanged.
- Application-family, child-editing and read-only status sessions now have a sliding
  90-minute inactivity timeout and retain the eight-hour absolute limit.
- A blocking warning appears five minutes before idle expiry. **Continue session**
  performs an authorised read, renews the server session and closes the warning.
- The OTP remains valid for 10 minutes. The existing 30-second resend cooldown and
  five-request/30-minute protection remain server enforced, but the interface now shows
  code validity separately so the cooldown cannot be mistaken for expiry.

## Student Form Changes

- Foundation displays as **Foundation (Prep)** while the stored value remains
  `Foundation`.
- Year 6 is removed from new Year Level of Entry choices. It remains visible only when
  already saved in an editable legacy draft.
- Our Lady of Rosary and St Mary's are removed from new current-school choices. An
  already-saved legacy selection remains visible only in that draft.
- **How many children?** becomes **How many other children?** and uses a required
  numeric input from 1 to 99 after the family answers Yes.
- The heading and country labels use the approved Student's Nationality and Citizenship
  wording. Main Language keeps the search catalogue; Other Languages is free text.
- General / Additional Needs uses the approved duty-of-care/support paragraph, removes
  the offer-impact assurance, renames Health professionals involved and changes Reports
  Attached choices to Yes/N/A.
- Medicare Expiry is required and stores month/year (`YYYY-MM`) rather than a full date.

## Editable Draft Migration

Opening an editable older application upgrades it once through the existing
conditional definition transaction. It preserves all answer keys and adds a revision
and audit event. Three representations are normalised:

| Previous value | V6.14 value |
| --- | --- |
| Reports Attached `No` | `N/A` |
| Medicare Expiry `YYYY-MM-DD` | `YYYY-MM` |
| Other children `7+` | `7` |

The upgrade revision records the changed keys and the audit event lists normalized
fields. It does not submit, reopen or duplicate the application.

## Deliberate Non-Changes

- OTP lifetime remains 10 minutes and resend throttling remains enforced.
- Existing answer keys, DynamoDB records, Sheet columns and Drive storage paths remain.
- EOI advances because it shares the family HTML, JavaScript and school catalogues.
- Acceptance and decline remain non-writing previews.
