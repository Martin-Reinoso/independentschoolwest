# V6.9 Address Assistance Change Map

## Scope

V6.9 adds optional Google Places address suggestions to the Application for Enrolment.
It does not add, remove, rename or reinterpret an application answer key.

Address assistance appears for:

- the student's primary address;
- each parent/guardian residential address; and
- each parent/guardian postal address when a separate postal address is required.

Doctor/practice addresses and the EOI address remain manual in this release.

## Family Experience

The optional **Find address** control appears above the existing address, suburb,
state, postcode and country fields. Selecting a suggestion fills those existing fields.
The family must review and can edit every populated value before continuing.

The manual fields remain the authoritative form controls. If Google is unavailable,
blocked or not configured, the helper changes to **Address search unavailable** and the
application remains fully usable and submittable by manual entry.

Suggestions are biased towards Australia but are not restricted to Australia. The form
does not request browser location permission or use device geolocation.

## Provider And Data Boundary

The browser sends the text entered into the Google search control directly to Google
Places. Rosewood requests only address components for the selected result. It does not
request or store a Google Place ID, coordinates, formatted-address payload, search
history or device location.

Only the existing structured Rosewood address values are autosaved to the authoritative
DynamoDB application record. Google is not an authoritative Rosewood record store.

The page sends only the `https://ffe.org.au` origin as referrer to support a
website-restricted browser key. Private invitation paths, tokens and query parameters
are not sent as referrer data.

## Key And API Controls

- Google Cloud project: `Rosewood Enrolment Production`
- Project ID: `notional-weft-504315-q9`
- Project number: `703660912246`
- Required APIs: Maps JavaScript API and Places API (New)
- Allowed websites: `https://ffe.org.au/*` and `https://www.ffe.org.au/*`
- API restrictions: only Maps JavaScript API and Places API (New)
- Runtime secret: `GOOGLE_MAPS_BROWSER_API_KEY` in the existing Rosewood AWS
  configuration secret

The key is not committed to Git. The backend returns it only inside an OTP-verified
application context. A browser key is necessarily visible to that authenticated
browser, so Google website and API restrictions remain the security boundary.

## Version And Compatibility

- Current EOI contract: `rosewood-eoi-2026.9`
- Current Application contract: `rosewood-application-2026.9`
- Storage schema: unchanged from V6.8
- V6.9 Application contract: byte-for-byte equivalent data contract to V6.8

Editable older drafts upgrade conditionally to V6.9 on verified open with all answers
and revisions preserved. Submitted, pending-signature, staff-review and completed
applications remain pinned to their submitted definitions.

The EOI question contract is unchanged; its version advances because EOI and
Application share the pinned family frontend assets.

## Cost And Availability

The low Rosewood volume is expected to remain within Google's monthly free usage caps.
Billing, a budget alert and conservative API quotas are still required because free
caps are not a security or spending control. Address assistance is non-critical: an API
quota, billing or provider failure must degrade to manual entry rather than block an
application.

## Release Gate

Do not mark live Google suggestions verified until all of the following pass:

1. Google billing verification is complete.
2. Both required APIs are enabled.
3. The production browser key has website and API restrictions.
4. The key is stored in the existing AWS configuration secret.
5. A synthetic invited application returns the configured helper after OTP.
6. Australian and overseas address selections populate the expected fields.
7. Manual entry still works with Google blocked.
8. Desktop/mobile and keyboard checks pass without console or CSP errors.
