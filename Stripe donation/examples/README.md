# Stripe Example Assets

This folder holds safe reference assets for the Stripe donation reporting workflow.

## Included

- [`stripe-deposit-reconciliation-example.xlsx`](/Users/jativaf/Library/CloudStorage/OneDrive-TheUniversityofMelbourne/Documents/GitHub/independentschoolwest/Stripe%20donation/examples/stripe-deposit-reconciliation-example.xlsx)

## Purpose

The example workbook shows:

- the expected tab layout
- the naming used in the reconciliation view
- the style and structure of the accountant-facing workbook

## Important

This workbook is sanitized.

It should contain:

- no live donor names
- no live donor email addresses
- no live donor messages
- no live Stripe receipt URLs
- no live payout references that should remain private

Real exports and live reconciliation workbooks should stay outside git.
